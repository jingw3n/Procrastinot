Motivation

As university students ourselves, we felt the frustration of managing academic responsibilities scattered across Canvas, Coursemology, Outlook, WhatsApp and more — with no single place to see everything.

Missing deadlines due to scattered platforms
Manual re-entry of every deadline wastes time
Large assignments left untouched until too late

This is a systems problem, not a discipline problem — one that software can meaningfully solve.

Features
📄
Syllabus PDF & Text Extraction CORE Upload PDF or paste text. Claude API extracts assignment names, due dates, exam dates, and parses vague dates ("mid-October") into structured formats.
🔗
Canvas LMS Integration CORE Connect Canvas via API token. Automatically sync assignments, due dates, and course info across multiple courses with real-time refresh.
📊
Unified Assignment Dashboard CORE Single view of all assignments from all sources. Filter by course, date range, type. Search, sort, and mark as completed or in-progress.
🗓
Workload Forecasting CORE Calendar view with deadline heatmap highlighting high-stress weeks, estimated hours per assignment, and weekly workload bar chart.
✂️
AI Assignment Decomposition CORE Select any assignment — Claude breaks it into 4–6 suggested weekly milestones with completion dates. Students can customise and edit.
👥
Collaborative Team Features EXT Create/join study groups, share assignment lists and milestones with teammates, view teammates' progress, and team workload alerts.
🛡
Admin Dashboard EXT View registered users, activity logs, and usage statistics (syllabi uploaded, active users). Basic account management and monitoring.
💾
Data Export & Privacy EXT Export as CSV, iCal, or PDF. Download full data as JSON (GDPR-style). Delete account and all associated data.

User Stories
Student: Upload a screenshot/text and have deadlines automatically extracted and populated.
Student: Connect Canvas so assignments sync without manual entry.
Student: See a visual forecast of upcoming workload to plan ahead.
Student: Break a large assignment into AI-suggested weekly milestones.
Student: Share group task lists with teammates on collaborative assignments.
Admin: View registered users, monitor activity, and manage accounts.
SE Principles
01
Agile Development Two-week sprints with defined goals from a maintained backlog. Sprint retrospectives documented in GitHub wiki.
02
Architecture Decision Records Every major technical choice documented in /docs/adr/ — context, options considered, trade-offs accepted.
03
Version Control GitHub with issues labelled by type and priority. CI/CD via GitHub Actions — tests run on every push.
04
Single Responsibility Modular FastAPI endpoints. Extraction logic, scheduling, and auth kept in separate, testable modules.
05
Usability Testing Two structured rounds with 5–8 students each. Findings logged as GitHub Issues and actioned next sprint.
